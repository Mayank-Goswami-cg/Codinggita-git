1. What is the difference between git clone and git init?
Answer. git init instializes the folder and git clone makes a clone of remote repository in local repository.

2. What does git status tell you?
Answer. git status displays whether the file is tracked or untracked and also shows if there is any need to commit.

3. What is the purpose of git add?
Answer. git add . sends all new created files to stagging area.

4. What is the difference between git diff and git diff --staged?
Answer. git diff displays the differences made in untracked files whereas git diff --staged displays the differences made in tracked or staged files.

5. What is the purpose of git commit?
Answer. git commit commits the changes made in the files in short it saves the changes.

6. What is the difference between git log and git log --oneline?
Answer. git log shows the commit id, auther name and email, date, time, day and commit message whereas git log --oneline shows commit id but in short form and shows commit message also.

7. What information can you see using git show?
Answer. git show displays commit id, author name and email, date day and time of commit, commit message and it also shows the difference is made in which file etc.

8. What does git pull do?
Answer. git pull pulls the changes made in remote repository into the local repository.

9. What does git push do?
Answer. It pushes the changes made in local repository into the remote repository.

10. What is a Git branch?
Answer. git branch is a command used to see the selected and available branch names.

11. What does git checkout do?
Answer. git checkout is used the change the selected branch in local repository.
